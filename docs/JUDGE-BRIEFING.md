# SAGIP — Reviewer & Judge Briefing

> **Offline-first emergency AI assistant for the Philippines.**
> "When the internet dies, your AI doesn't."
> AppBuildersPH Hackathon 2026 · Theme: Local AI · Category: Disaster Response

---

## 1. What it is

SAGIP is a native Android app that guides Filipinos through medical emergencies,
disasters, and survival situations with **zero connectivity**. It combines an
on-device large language model with 112 curated, source-cited emergency guides
(English + Tagalog), personalized to the user's profile, illustrated step by
step. The core experience — ask, browse, search, SOS, contacts — works entirely
in airplane mode.

**60-second evaluation path:** enable airplane mode → ask *"Someone is bleeding
heavily"* → ask *"May baha na papasok sa bahay, ano gagawin ko?"* → open a
category → check the source citation and severity banner on any answer.

---

## 2. Why Local AI (the case for this product)

Typhoons destroy cell signal in the Philippines every year — precisely when
emergency guidance is needed most. A cloud assistant is a dead icon in that
moment. SAGIP inverts the dependency: model, knowledge, and personal data all
live on the phone, so the product's core value exists **only because the AI
runs locally**. Local execution additionally gives zero-latency answers, zero
inference cost, and privacy no cloud product can match (medical profile and
location never leave the device). Remove the local AI and there is no product.

## 3. Stack

| Layer | Choice |
|---|---|
| App | Native Android — Kotlin + Jetpack Compose, Gradle |
| On-device runtime | LiteRT-LM (`litertlm-android` 0.14.0) with mobile GPU delegate |
| Primary model | Google Gemma 4 E2B (`.litertlm`, 2.4 GiB) — first token ≈ 0.7–1.8 s, full answer ≈ 3–10 s on the S23 Ultra GPU |
| Fallback models | Gemma 3n E2B, Gemma 3 1B INT4 (~560 MB); `ModelConfig` picks the first file present on the device |
| Retrieval | Keyword retriever (CAG) over bilingual tags/topics/titles + relevance gate; `Retriever` interface is a seam ready for vector search |
| Knowledge | 13 JSON packs, `app/src/main/assets/packs/` — 224 chunks (112 topics × EN/TL twins), schema in `docs/PACK-AUTHORING-GUIDE.md` |
| Art | 13 hand-built SVG category covers + 121 PNG topic images, `app/src/main/assets/illustrations/` (+ `index.json` manifest) |
| Profile | Local only (`SharedPreferences` JSON) — name, birthday/age, blood type, allergies, conditions, meds, emergency contact, area, language, household flags. Chat history is a local JSON file. |
| Voice | Android `SpeechRecognizer` (optional; on-device only when the phone has its offline speech pack) |
| Permissions | **No `INTERNET` permission** (verified in the merged manifest). Only `READ_CONTACTS` (pick the emergency contact), `ACCESS_FINE/COARSE_LOCATION` (area for the contact directory), `RECORD_AUDIO` (voice input), `CALL_PHONE` ("call my wife"; falls back to the dialer if denied) |
| Tests | 109 JVM unit tests (`./gradlew :app:testDebugUnitTest`): data layer, retrieval, follow-ups, prompt builder, contact mentions, art-manifest mapping |

## 4. Key techniques

1. **Cache-augmented generation, deliberately.** No on-device embedder model —
   keyword retrieval over curated bilingual tags is cheaper on RAM/battery,
   deterministic, and auditable. A small model + exact retrieval beats a big
   model + fuzzy retrieval for safety-critical steps.
2. **Grounded generation, with a verbatim safety net.** Gemma writes the
   answer *from the retrieved guides* and the user's profile, adapting it to
   the situation ("I saw a snake" ≠ "I was bitten"). A watchdog detects stalls
   and repetition loops and falls back to the guide steps verbatim, so the
   user always gets a usable answer.
3. **Defense in depth.** Retrieval floor (no match → honest "I don't know" +
   SOS redirect); SCOPE gate with `OFF_TOPIC` sentinel for non-emergency
   prompts; phone numbers answered deterministically from `contacts.json`,
   never generated by the model.
4. **Small-model prompt tuning.** Guidance placed front-and-center, language
   instruction last (recency effect) — verified on-device to produce real
   Tagalog numbered steps instead of rule-parroting.
5. **Personalization by relevance.** Each chunk declares relevant profile keys
   (`allergies`, `household_infant`, …); the prompt builder injects only what
   the guidance needs. Questions about the user's *own* allergies, food,
   medicine or health get the whole saved profile (with explicit "none saved"
   so the model never guesses). Disaster guides add a "check on your family"
   nudge to the emergency contact; other contacts are offered to the model as
   optional and a call button appears only if the answer mentions them.
5b. **Conversation memory.** Short follow-ups ("paano kung walang response?")
   are retrieved together with the question that started the topic, and the
   last turns are passed to the model, so context survives.
6. **Bilingual by data, not translation.** Every topic ships as an EN+TL twin
   authored independently, so Tagalog answers come from Tagalog source text.

## 5. Design sources (unslop.site)

Interface and brand direction were developed with
[unslop.site](https://unslop.site) references as studied inspiration — hierarchy,
typography, color, spacing, density, and interaction vocabulary adapted to an
emergency product, never copied wholesale:

- **AI Chat reference** (Mobile Apps) → the original dark-canvas chat system:
  soft-white text, single accent orb, asymmetric bubbles, pill input, severity
  banner and citation lines layered on top for the safety use-case.
- **Photo Journal reference** (Mobile Apps / Core Apps) → the current browse
  experience: masonry-style category grid, hairline borders, chip treatment,
  FAB pattern, caption-over-art overlays adapted into source-citation overlays.
- **Brand assets** — the SAGIP app icon, mascot, and wordmark were generated
  with unslop.site tooling and refined for the product.

## 6. Content & safety position

- Every chunk traces to a **named authority** (Philippine Red Cross, DOH, WHO,
  NDRRMC, PHIVOLCS, PAGASA, BFP, PCG, PNP, DSWD, LTO, DENR).
- No drug dosages beyond what sources state; no diagnosis; critical topics end
  by directing to professional help/911.
- First-launch disclaimer: guidance from trusted manuals, not a substitute for
  professional medical care.
- **Review status (honest):** pack text follows the authoring guide's
  source-or-omit rule; of 121 AI-generated topic images, a sample has been
  human-verified and two defective frames were rejected and removed — the
  remainder await position review before any production use. Rejected-frame
  log: `docs/PACK-AUTHORING-GUIDE.md` §9.

## 8. Reproduction (no deployment needed)

```bash
./gradlew :app:installDebug                              # USB-connected Android device, USB debugging on
./scripts/push-model.sh ~/Downloads/gemma-4-E2B-it.litertlm   # copies to /data/local/tmp/llm/gemma-4-e2b-it.litertlm
./gradlew :app:testDebugUnitTest                         # 109 unit tests
```

Tested on Samsung Galaxy S23 Ultra SM-S918B (Snapdragon 8 Gen 2, 12 GB RAM, Android 16). Headless check:
`adb shell am broadcast -a dev.darl.sagip.DEBUG_ASK --es q "<question>" -p dev.darl.sagip`
(logs: `SagipTest` / `SagipGen`; quote multi-word questions on the device side as shown). Full instructions: `README.md`.

## 9. Judging-criteria mapping

- **Problem & Usefulness (25%)** — disasters + signal loss coincide yearly in
  PH; target user is any Filipino with a phone; offline emergency guidance has
  no cloud substitute.
- **Local AI Implementation (25%)** — inference, retrieval, speech, and data
  are 100% on-device; removing local AI removes the product.
- **Technical Execution (20%)** — works in airplane mode live; GPU inference,
  guardrailed generation with stall/loop watchdog and verbatim fallback,
  109 tests behind the data/retrieval/prompt layers.
- **Innovation (15%)** — grounded generation over a curated bilingual corpus
  lets a 2B on-device model answer safely; profile-aware answers; deterministic
  contact handling and direct "call my wife"; 13-pack coverage beyond first aid.
- **Product & Demo Quality (15%)** — Photo-Journal browse, illustrated guides,
  EN/TL toggle, rehearsed airplane-mode demo script (`PLAN.md` §8).
